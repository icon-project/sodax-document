# 4. Examples

<a href="https://docs.sodax.com/developers/packages/examples/demo" class="button secondary" data-icon="browser">Demo app</a> - Vite + React, one page per feature service. The provider stack in `providers.tsx` is the piece to copy for a React integration.

<a href="https://docs.sodax.com/developers/packages/examples/node" class="button secondary" data-icon="terminal">Node examples</a> - Backend scripts, one file per chain or feature. Start with `pnpm logging`, the only one that needs no key, no funds and no network.

<a href="https://docs.sodax.com/developers/packages/examples/wallet-modal" class="button secondary" data-icon="wallet">Wallet modal example</a> - The connect flow on its own — no design system, no DeFi logic.

<a href="https://docs.sodax.com/developers/packages/foundation/swaps-api/example" class="button secondary" data-icon="plug">Swaps API example</a> - Drives `@sodax/swaps-api` directly, without `@sodax/sdk` or `@sodax/dapp-kit`.

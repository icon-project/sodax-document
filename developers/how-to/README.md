# How to

Task-oriented guides for building on SODAX. Start with **Configure SDK** if you are wiring the SDK up for the first time, or jump straight to the flow you need.

### Getting set up

<a href="https://docs.sodax.com/developers/how-to/configure_sdk" class="button secondary" data-icon="gear">Configure SDK</a>- Constructor options, custom RPC and per-feature config

<a href="https://docs.sodax.com/developers/how-to/nextjs" class="button secondary" data-icon="window">Install with Next.js</a>- Project setup, provider wiring and Turbopack troubleshooting

<a href="https://docs.sodax.com/developers/how-to/wallet_providers" class="button secondary" data-icon="wallet">Setup Wallet Providers</a>- Per-chain wallet providers for signing and broadcasting

### Building a flow

<a href="https://docs.sodax.com/developers/how-to/how_to_make_a_swap" class="button secondary" data-icon="rotate">Make a Swap</a>- End-to-end intent-based swap, from quote to settlement

<a href="https://docs.sodax.com/developers/how-to/bitcoin-integration" class="button secondary" data-icon="bitcoin-sign">Bitcoin Integration</a>- Bitcoin as a source or destination chain

<a href="https://docs.sodax.com/developers/how-to/estimate_gas" class="button secondary" data-icon="gas-pump">Estimate Gas</a>- Estimate gas before submitting a transaction

<a href="https://docs.sodax.com/developers/how-to/stellar_trustline" class="button secondary" data-icon="star">Handle Stellar Trustline</a>- Trustline requirements for Stellar sources and destinations

### Running in production

<a href="https://docs.sodax.com/developers/how-to/logging" class="button secondary" data-icon="file-lines">Logging</a>- Route SDK diagnostics to Sentry, Datadog, Pino or your own sink

<a href="https://docs.sodax.com/developers/how-to/monetize_sdk" class="button secondary" data-icon="hand-holding-dollar">Monetize SDK</a>- Partner fees on the flows you integrate

<a href="https://docs.sodax.com/developers/how-to/testnet" class="button secondary" data-icon="circle-question">Is SODAX on Testnet?</a>- Where to test against real infrastructure
